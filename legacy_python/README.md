# Архив прежнего Python-сервера

Эти файлы сохранены только как справочный материал для переноса и сверки старых форматов. Они не используются Rust-сервером и не являются поддерживаемым способом запуска Frokla.

Рабочие сервер, API, модерация и SQLite находятся в `src/` и запускаются через Cargo. Единственный актуальный Python-компонент — `../local_ai/train.py`, который обучает и экспортирует ONNX-модели.
