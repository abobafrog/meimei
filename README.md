# Тима — следы на снегу

Адаптивный личный сайт на HTML, CSS и JavaScript без сторонних библиотек.

## Запуск

Откройте `index.html` в браузере либо запустите локальный сервер из этой папки:

```sh
python3 -m http.server 4173
```

Затем откройте <http://localhost:4173>.

Форма гостевой книги проверяет ник, длину сообщения и запрещённый контент, но не отправляет и не сохраняет записи. Для реальной модерации потребуется подключить сервер.

Исходная фотография Мей-Мей находится в `mei-mei.jpg` и не редактировалась.
